# AI 图影生成（自定义模型）

钉钉 AI 表格 AI 字段（FaaS 插件）。基于你自带的 OpenAI 兼容 API Key，用**提示词 + 参考图**为每行记录生成图片或视频，结果写入当前字段的附件单元格。

## 功能

- **图片**：文生图 / 单图编辑 / **多参考图**（如 线稿 + 面料 → 成衣平铺图）
  - 走 `/images/generations`（无参考图）或 `/images/edits`（有参考图，多张自动以 `image[]` 传入）
- **视频**：文生视频 / **图生视频**（参考图直传公网链接，本地不下载）
  - 自动识别两种上游协议：Sora 式（`/v1/videos` 任务制，如 veo、grok、seedance）与百炼式（`/alibailian/...` 任务制，如 wan、happyhorse 系列；图生视频必须走这类）
  - 提交后自动轮询等待（最长约 12 分钟），完成后以附件形式写入 mp4
- **分辨率**：图片 `1024x1024 / 1024x1536 / 1536x1024 / 默认`；视频 `480p / 720p / 1080p`；视频时长 `3/5/10s`
- **Key 随时换**：字段配置 →「账户授权」，由 AI 表格加密代管，不进代码、不进仓库
- **换服务商**：改「接口 Base URL」+「模型名称」即可（域名需在本仓库 `src/index.ts` 的 `WHITELIST` / `ALLOW_HOSTS` 内声明）

## 字段配置项

| 配置 | 说明 |
|---|---|
| 输出类型 | 图片 / 视频（视频约需 1~5 分钟自动等待） |
| 模型名称 | 图片：`gpt-image-2`、`qwen-image-3.0`…；视频：`veo_3_1-fast`（文生视频）、`happyhorse-1.1-i2v`、`wan2.6-i2v`（参考图生视频）… |
| 接口 Base URL | 留空 = OpenAI 官方；中转服务商填其兼容地址，如 `https://api.openlux.ai/v1` |
| 提示词 | 选择本表的文本字段，其内容作为 prompt |
| 参考图 | 可多选附件字段，按勾选顺序；提示词里用「第1张图/第2张图」指代 |
| 输出尺寸 / 视频时长 / 视频协议 | 见上，视频协议保持"自动"即可 |

## 常见问题

- **必要字段为空**：该行提示词列为空，属正常拦截
- **红字"AI 服务调用失败"**：核对 Base URL、模型名、Key 与额度；错误气泡附带 HTTP 状态与响应片段可直接复制排查
- **视频报 vid_failed / 提交失败**：该模型可能不归属两种已知协议，联系开发者扩充
- **图生视频不生效**：模型需为百炼式（happyhorse / wan 系列 i2v）；Sora 式带参考图会明确报配置错误

## 本地开发/调试

```bash
npm install
cp config.example.json config.json   # 填调试用 key（config.json 不提交）
npm run typecheck
npm run start                        # 端口 8088，配合 AI 表格「AI 字段开发助手」FaaS 调试
```

本地调试仅触发现会话新建的字段列，且不支持自动更新；正式使用请走上架发布。
